## 📖 Overview
This repository contains the front-end assets and styling for a retro gaming and board game website. It showcases foundational front-end web development skills, custom typography integration, and digital asset management.

## ✨ Key Features
* **Custom Typography:** Integrated the complete Roboto font family (Black, Bold, Light, Medium, Regular, Thin) for cohesive UI/UX typography.
* **Thematic Styling:** Custom CSS stylesheets (`style.css`) designed to create an immersive retro gaming aesthetic.
* **Asset Integration:** Incorporates custom imagery and digital assets referencing classic gaming, including SNES and OutRun aesthetics.

## 🛠️ Tech Stack
* **Markup & Styling:** HTML5, CSS3
* **Typography:** Custom Web Fonts (Roboto)
* **Version Control:** Git & GitHub
